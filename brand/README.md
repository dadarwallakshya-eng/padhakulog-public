# Padhaku Log brand kit

## Files

| File | Use it for |
|---|---|
| `padhakulog-logo-ink.png` | Main logo on light backgrounds (transparent, 1680 px wide) |
| `padhakulog-logo-white.png` | Logo on dark backgrounds (white letters, transparent) |
| `padhakulog-logo-ink@2x.png`, `padhakulog-logo-white@2x.png` | Same logos at 3360 px wide, for posters |
| `padhakulog-logo-on-paper.png`, `padhakulog-logo-on-ink.png` | Logo with background already in place |
| `padhakulog-icon-1024.png` | App icon / profile picture (rounded) |
| `padhakulog-icon-1024-square.png` | Same icon with square corners (Instagram, WhatsApp DP) |
| `padhakulog-brand-sheet.png` | One page with all colours and fonts |

The @2x files are enlarged from the original 2000 px artwork, so they are not sharper than the 1x ones.
For big prints, get the logo redrawn as a vector (SVG).

## Colours

| Name | Hex | Where |
|---|---|---|
| Ink | `#17181C` | Text, buttons, outlines |
| Highlighter | `#FCE07A` | The one accent: main button, highlights, stickers |
| Paper | `#FBFAF6` | Page background (never pure white) |
| Night | `#0F1013` | Call screen and dark backgrounds |
| Pencil | `#4A4C52` | Secondary text |
| Line | `#E6E3DA` | Borders and dividers |

## Fonts (all free, Google Fonts)

- **Bricolage Grotesque**, ExtraBold: headings ("Chalo, baat karein.")
- **DM Sans**: body text and buttons
- **Kalam**, Bold: handwritten notes and stickers ("30 sec baat = dost!")

## Rules of thumb

- Yellow only as a highlight under words, the main button, or a sticker. Never as body text on white (too light to read).
- Thick ink outlines (2 px on screen) and a yellow block shadow are part of the look.
- Copy is friendly Hinglish, with an English version. No college names on public material.

## Canva Brand Kit

1. Canva → Brand → Brand Kit → Logos: upload the two logo PNGs and the icon.
2. Colours: add the six hex codes above.
3. Fonts: set Heading = Bricolage Grotesque, Subheading = DM Sans Bold, Body = DM Sans. If a font isn't in Canva's library, download it from fonts.google.com and upload it.
